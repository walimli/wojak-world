## 2026-11-03

Search runs from the Search button or Enter in the search field, and again when Favorites only, Tagged only, or Hide missing changes. Typing no longer searches on each keystroke. Tagged only keeps images that have at least one manual tag.

Search text accepts AND, OR, NOT, quoted phrases, and parentheses. Separate words still mean AND, and a bare word is still a prefix match. The `?` button by the search box lists the operators. Invalid search text opens a message dialog instead of showing a database error. Filename token indexing is unchanged.
